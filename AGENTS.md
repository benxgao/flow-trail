# AGENTS.md

- This repository ships a skill, not an app. `SKILL.md` is the product; `README.md` is the pitch.
- The skill is markdown. Any harness that can read a file can follow it; no plugin is required.
- Working in this repo: `docs/writing.md` is binding, and `bash scripts/prose-lint.sh` checks it.
- A rule change cites a measurement or a run, per [CONTRIBUTING.md](CONTRIBUTING.md).
- `examples/login-refactor/` is a real board. Its numbers came from runs; do not retype them.
- `.claude-plugin/` is Claude Code's marketplace manifest. One install route, not the skill.
